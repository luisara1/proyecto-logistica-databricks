
Esta carpeta contiene la configuración de seguridad y gobierno
implementada mediante Unity Catalog.

Incluye:

- Gestión de permisos basada en grupos.
- Grants sobre catálogo, schemas y tablas.
- Acceso diferenciado para administración, ETL y BI.
- Configuración de Delta Sharing.
- Share de tablas Gold.
- Recipient externo controlado.
